# Platform pivot to Tauri + React + shadcn

Type: grilling
Status: resolved

## Question

Given discomfort with Native SDK house styling and preference for React/CSS/web animations, should Toudou leave Native SDK for Tauri or Electron?

## Answer

**Tauri 2 + React + Vite + shadcn.** Full styling liberty for a Copper-inspired UI; TypeScript end-to-end; thinner than Electron. Global capture still needs a thin macOS companion (research 01). Native SDK work becomes throwaway/reference. Electron deferred unless Tauri is blocked.
